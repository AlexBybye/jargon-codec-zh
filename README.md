# 🧑‍💼 我要成为互联网黑话高手

**把人话压进 PPT，也把 PPT 放回人间。**

一个在「普通话」与「互联网 / AI 大厂黑话」之间双向转换的 Codex Skill。

</div>

---

你一定见过这种句子：

> 聚焦核心场域，拉通关键链路，以组合拳沉淀方法论，最终形成端到端业务闭环。

字都认识，连起来像在参加晋升答辩。

`jargon-codec-zh` 可以把它翻回普通话，也可以反向操作：把一句朴实无华的工作安排，升级成让会议室空气突然凝重的大厂表达。

> **黑话可以拉满，事实不能缩水。**

## 能做什么

- **黑话 → 普通话**：拆掉包装，说明到底是谁、要做什么、何时完成、如何验收。
- **普通话 → 大厂黑话**：提供 `自然` 和 `无所不用其极` 两个明确档位。
- **覆盖互联网与 AI 语境**：产品、运营、增长、商业、研发、管理、RAG、Agent、MCP、Eval 等统一处理。
- **忠实转换**：保留人物、数字、范围、条件、否定、因果、截止时间和承诺强度。

## 30 秒看懂黑话浓度

只有两个档位；`bilingual` 是 `无所不用其极` 的附加开关，不是第三档。

### 原始普通话

> 李想负责在周五前修好导出按钮。先向华东地区 10% 的用户开放；错误率高于 1% 就恢复旧版本，不能据此承诺留存会提升。

### 🟢 `自然`：真实工作可用

> 导出按钮修复由李想负责，周五前完成；首轮仅面向华东地区 10% 的用户灰度。错误率高于 1% 就回滚旧版本，本次结果不外推为留存提升。

适合周报、方案、会议纪要和正常同事之间尚能互相理解的交流。

### 🔴 `无所不用其极`：建议搭配激光笔使用

> 围绕导出链路稳定性目标，由李想作为单线程 owner 牵引修复闭环，并在周五前完成交付。首轮聚焦华东场域，以 10% 用户灰度作为验证抓手；错误率一旦突破 1% 阈值，即执行旧版本回滚。本轮阶段性结果不外推为留存提升承诺。

适合整活、述职模拟、PPT 氛围建设，以及检验一句话究竟能承载多少抓手。

### 🟣 `无所不用其极 + bilingual`：英文只负责点睛

> 围绕导出链路稳定性目标，由李想作为单线程 `owner` 牵引修复闭环，并按周五 `timeline` 完成交付。首轮 `scope` 聚焦华东场域，以 10% 用户灰度作为验证抓手；错误率一旦突破 1% 阈值，即执行旧版本 `rollback`。本轮阶段性 `output` 不外推为留存提升承诺。

bilingual 的精髓是中文句内 code-switching：**每句只自然混入 1–2 个英文词**。不写成“闭环（closed loop）”，不把整段 jargon 全翻成英文，也不为了显得国际化而把中文句子送去海归。

## 还能反向解码

### 输入

> 聚焦退款链路最小闭环，拉通 Agent 与 MCP 工具侧能力，首轮仅在华南 10% 用户中灰度，异常即回滚。

### 转成普通话

> 先确定退款流程必须完成哪些步骤，再让 AI 助手（Agent）通过 MCP 协议连接所需工具。第一批只向华南地区 10% 的用户开放，出现问题就恢复旧版本。

不是把“赋能”机械替换成“帮助”，而是尽量还原句子真正描述的对象、动作和边界。原文没有的信息不会凭空补上。

## 安装

把 Skill 复制到 Codex 的个人 Skills 目录：

```bash
git clone https://github.com/AlexBybye/jargon-codec-zh.git ~/.codex/skills/jargon-codec-zh
```

随后在新任务中使用 `$jargon-codec-zh`。

## 使用方式

### 转成普通话

```text
使用 $jargon-codec-zh，把下面这段大厂黑话转成普通话：

围绕用户增长核心场域，拉通公私域触点，以内容矩阵为抓手撬动自然量，沉淀可复制打法。
```

### 转成自然档黑话

```text
使用 $jargon-codec-zh，把下面这段话转成大厂黑话。
档位：自然

先统一目标，协调产品、研发和测试改完接口，月底验收。
```

### 把浓度拉满

```text
使用 $jargon-codec-zh，把下面这段话转成大厂黑话。
档位：无所不用其极

先统一目标，协调产品、研发和测试改完接口，月底验收。
```

### 浓度拉满，再开 bilingual

```text
使用 $jargon-codec-zh，把下面这段话转成大厂黑话。
档位：无所不用其极 + bilingual
每句只混入 1–2 个英文词，中文黑话保持主体。

先统一目标，协调产品、研发和测试改完接口，月底验收。
```

如果没有指定档位，Skill 会先让你在 `自然` 与 `无所不用其极` 之间明确选择，不会暗中替你决定黑话浓度。

## 黑话守则

- 可以把“先试一下”写成“以灰度验证作为抓手”，但原文没有灰度范围时不能编一个 10%。
- 可以加入 owner，不能凭空创造负责人。
- 可以说“形成闭环”，不能把“计划完成”升级成“已经落地”。
- 可以让句子更像大厂，不能让数字、条件、风险和截止时间从句子里消失。
- `RAG` 不等于准确，`MCP` 不等于工具自动可用，`Agent` 也不等于完全自主。
